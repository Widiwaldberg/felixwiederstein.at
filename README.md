# felixwiederstein.at

Persönliche Website von Felix Wiederstein — Fotograf und Bikelife Media Creator.

## Worum geht's

Die Website präsentiert zwei Bereiche:

- **Family & Friends** — Portraitsessions, Familien- und Gruppenfotos, Geburtstage, Freundschaftsfotos und spontane Reportagen.
- **Bikelife Media** — Action- und Lifestyle-Fotografie, Video Production, Event Coverage, Social Media Content und Motorrad Portraits.

## Aktueller Stand

Single-Page-Website (`index.html`) mit:

- **Scroll-Intro** — Beim Scrollen zieht sich das Hero-Bild zusammen und gibt zwei Content-Panels frei (Family & Friends / Bikelife Media), die von den Seiten einfahren.
- **Signature-Animation** — Der Name „Felix Wiederstein" baut sich per Clip-Path-Animation auf.
- **Stage 3** — Drei anklickbare Panels (Family & Friends / Video Work / Bikelife Media) mit Hover-Effekten.
- **Custom Cursor** — Gelernter Kreis-Cursor mit Lenis Smooth Scroll und GSAP ScrollTrigger.

## Tech Stack

- Vanilla HTML/CSS/JS
- [GSAP](https://greensock.com/) + ScrollTrigger
- [Lenis](https://github.com/darkroomengineering/lenis) Smooth Scroll
- Google Fonts: Cormorant Garamond, Anton, Barlow Condensed, Great Vibes
